# SOP to BPMN Converter

An automated tool designed to parse Standard Operating Procedures (SOPs) from Microsoft Word documents and convert them into BPMN 2.0 XML standard diagrams.

### 📂 Project Structure
```markdown
sop-to-bpmn/
├── generate_sop.py         # Utility script to generate a valid sample input_sop.docx
├── input_sop.docx          # The input document (generated by script or provided manually)
├── main.py                 # The entry point orchestration script
├── requirements.txt        # Python dependencies
└── src/
    ├── __init__.py
    ├── models.py           # Internal graph representation (Nodes, Edges, Pools)
    ├── parser.py           # Regex and logic to extract steps/decisions from .docx
    └── renderer.py         # BPMN XML generation logic

```

## 🚀 Usage

### 1. Generate Input Data

If you do not have an existing SOP file, use the generator script to create a sample standard operating procedure.

```bash
python generate_sop.py

```

* **Result:** Creates `input_sop.docx` in the root directory containing sample steps.

### 2. Run the Converter

Execute the main script to parse the Word document and generate the BPMN file.

```bash
python main.py

```

* **Input:** Reads `input_sop.docx`.
* **Process:** 
    -  **Parser:** Extracts text and identifies logic (sequence vs. decision).
    -  **Models:** Builds an internal graph of the process.
    -  **Renderer:** Converts the graph into valid BPMN XML.
* **Output:** Generates a `.bpmn` or `.xml` file (depending on configuration in `main.py`).

## 🧩 Module Overview
* **`src/parser.py`**
    * **Logic Engine:** Implements `SimpleSOPParser` to convert text lines into graph objects.
    * **Gateways:** Detects phrases like "Check if..." or question marks ("?") to create Exclusive Gateways.
    * **Conditions:** identifies "If yes/no..." patterns to create labeled sequence flows connecting back to the most recent gateway.
    * **Tasks:** Treats standard text lines as sequential tasks.

* **`src/models.py`**
    * **Data Structures:** Defines the core graph components: `Node` (supporting types: start, end, task, gateway), `Edge`, and `ProcessGraph`.
    * **Identity Management:** Automatically assigns unique UUIDs to every node and flow to ensure valid BPMN referencing.

* **`src/renderer.py`**
    * **XML Generation:** Implements `BPMNRenderer` using `lxml` to build a compliant BPMN 2.0 file.
    * **Semantic Mapping:** Converts internal nodes to specific BPMN tags (e.g., `<bpmn:exclusiveGateway>`, `<bpmn:startEvent>`).
    * **Diagram Interchange (DI):** Includes a layout engine that calculates X/Y coordinates to generate the `<bpmndi:BPMNDiagram>` section, ensuring the process is visually rendered (not just logically defined) when opened in viewers like Camunda or bpmn.io.

## 📦 Requirements

* `python-docx`: For reading Word documents.
* `lxml`: For high-performance XML creation and parsing.
